# Calculator Simulator

A web app that replicates approved GCSE / A-level calculators. Pick a calculator at the start, then use a pixel-faithful, fully functional replica of it.

> This is an **unofficial, educational** project. It is not affiliated with, endorsed by, or connected to Casio, Texas Instruments, Sharp, or any exam board.

## Status

Planning stage. See [`docs/PLAN.md`](docs/PLAN.md) for the full design document.

## What's planned

- A **selector screen** where you choose a calculator model.
- **Fully functional replicas** (not static images) of popular UK exam calculators.
- **Tier 0 (MVP):** Casio fx-83GT CW+, fx-85GT CW+, fx-991CW+.
- **Tier 1:** Casio fx-CG50, fx-CG100 (graphing).
- Desktop + mobile, keyboard support, offline (PWA).

## Stack (proposed)

Vite · React 18 · TypeScript · decimal.js · DSEG fonts · Vitest + Playwright.

## Getting started

Not yet scaffolded. Once the MVP is built:

```bash
npm install
npm run dev
```
